# Логотипы магазинов маркета

Исходники всех логотипов, которые сейчас стоят у магазинов в приложении и на
публичных веб-страницах. Эта папка — **склад оригиналов**, из неё логотипы
раскладываются по двум рабочим местам.

## Правило именования

Файл называется **ровно как `stores.slug`** в БД (он же `parser_class`, он же
ключ в реестре мобилки): `long_play.png`, `plastinka_com.png`. Не `longplay`,
не `long-play` — иначе картинка не подхватится нигде.

## Куда раскладывается

| место | путь | кто читает |
|---|---|---|
| Приложение | `Mobile/assets/store-logos/<slug>.png` | `Mobile/components/market/StoreLogo.tsx` |
| Веб | `Backend/app/web/static/store-logos/<slug>.png` | `_offer_dict` в `Backend/app/web/routes.py` |

## Как добавить логотип новому магазину

1. Положить `<slug>.png` сюда.
2. Скопировать в оба пути из таблицы выше.
3. Добавить магазин в `STORE_REGISTRY` в `StoreLogo.tsx` — `require(...)`
   обязан быть статическим, Metro не умеет динамические.
4. Добавить slug в `_LOCAL_STORE_LOGOS` в `routes.py`.

Шаги 2–4 сторожит `Backend/tests/test_store_logos.py`: он падает, если список
и папка разошлись. Забыть шаг 4 иначе нельзя заметить — веб просто нарисует
монограмму при живом PNG, без ошибки и без записи в лог.

## Требования к картинке

- **PNG, квадрат.** Ходовой размер — 447×447 (found, rotaryrecords, skifmusic,
  long_play). Минимум 300×300: логотип рендерится до 64pt, на ретине это ~192px.
- Прозрачность допустима — под картинкой лежит `bgColor` из реестра мобилки.
  У непрозрачных (long_play — чёрный круг на белом поле) `bgColor` виден только
  в момент загрузки.
- `resizeMode: contain`, скругление даёт контейнер — вписывать логотип в круг
  или в скруглённый квадрат самому не нужно.
