# App Store screenshots

Кадры для карточки в App Store: **1290×2796** — размер подходит и под слот 6.7"
(iPhone 15/16 Plus), и под 6.9" (16/17 Pro Max), App Store Connect принимает оба.

Собираются из реальных скриншотов приложения: фон — фирменный кобальтовый градиент
`T.gradients.brand` + ember-акцент из `Mobile/constants/theme.ts`, шрифты — те же
`Rubik Mono One` (плашка) и `Inter ExtraBold/Medium` (заголовок и подпись).

## Сборка

```bash
python3 Design/appstore/build.py
```

Нужен Google Chrome в `/Applications` (рендер headless) и `sips` (есть в macOS).
Скрипт сам ресайзит исходники под ширину экрана мокапа — апскейла в браузере нет,
пиксели 1:1.

## Выгрузка в Figma

```bash
python3 Design/appstore/build_svg.py
```

Кладёт послойные SVG в `figma/` — по 7 КБ. Импорт: перетащи файл на холст Figma,
он развернётся в дерево слоёв (`Фон`, `Канавки`, `Ember-свечение`, `Текст`, `Мокап`),
где каждая строка — редактируемый текстовый слой.

**Скриншоты в SVG не вшиты.** Внутри мокапа лежит пустой слот
`Экран-вставить-скриншот` со скруглением 75 — PNG кладётся в него уже в Figma
(выделить слот → Fill → Image). Поэтому файл весит килобайты.

Ещё два момента при импорте:

- **Шрифты.** В SVG стоят `Inter` и `Rubik Mono One` по имени — в Figma оба есть
  из коробки. А вот в браузере превью будет с системной подменой, если Inter не
  установлен в системе; это нормально и на Figma не влияет.
- **Тени и размытия.** SVG-фильтры не используются: Figma растрирует слои с
  фильтрами и послойность теряется. Мягкие переходы собраны на градиентах, а тень
  под корпусом — отдельный слой `Тень`. Если нужна честная тень, удали его и
  повесь на `Корпус` нативный Drop shadow.

Геометрия текста не задана руками: [measure.py](measure.py) прогоняет тот же
HTML через headless Chrome и снимает реальные бейзлайны и ширины, поэтому SVG
ложится на PNG пиксель в пиксель. Если поменять кегль в `build.py`, `measure.py`
об этом скажет ассертом, а не разъедется молча.

## Как менять

Тексты, акценты и порядок — список `SLIDES` в [build.py](build.py). Один слайд =
`tag` (плашка), `title` (2 строки, `\n` — жёсткий перенос), `sub` (2 строки),
`glow` (холодные пятна фона) и `ember` (тёплое пятно под корпусом).

Чтобы добавить кадр — положи скриншот в `src/`, допиши запись в `SLIDES`, пересобери.
Готовые кадры лежат в `export/`, а не в `build/`: корневой `.gitignore` глушит
любую папку с таким именем, и экспорт просто не попал бы в репозиторий.

Геометрия мокапа общая: `SCREEN_W` (ширина экрана), `BEZEL`, `PHONE_TOP`.
