## 1. Рыночный контекст

### 1.1. Россия — идеальный тайминг

- Покупки винила **+15% в 2025, +32% к 2023**. Средняя цена пластинки 1978₽ ([3DNews](https://3dnews.ru/1137266/spros-na-vinilovie-plastinki-v-rossii-vzletel-na-15-v-2025-godu), [Retail.ru](https://www.retail.ru/news/prodazhi-vinilovykh-plastinok-v-rossii-vyrosli-za-dva-goda-na-32-22-fevralya-2026-274792/))
- **Аудитория омолодилась:** средний возраст покупателя упал с 40–45 лет (2020) до 30–33 (2025); 18–24 — самая быстрорастущая группа; лидеры по объёму — мужчины 25–34 ([Sostav](https://www.sostav.ru/publication/zumery-i-millenialy-razognali-prodazhi-vinilovykh-plastinok-81903.html))
- 70%+ продаж — онлайн → маркет-раздел бьёт точно в канал
- «Мелодия» перезапустила завод в Новосибирске → живой RU-контент, локальные прессы

### 1.2. Глобальные тренды

- 19-й год роста подряд в США, 47.9M юнитов в 2025 ([MyVinyls](https://myvinyls.app/blog/2026/04/what-vinyl-sales-data-means-for-collectors-2026/))
- 55–58% новых покупателей — младше 35; 76% Gen Z покупают ради физического владения и ритуала ([MyVinyls Gen Z](https://myvinyls.app/blog/2026/04/gen-z-driving-vinyl-collecting-2026/))
- Драйвер спроса — лимитки, варианты, цветной винил ([Klangheimat](https://www.klangheimat.de/news/lng/en/vinyl-2025-2026-trends-analyse.html?language=en))

**Портрет целевого юзера:** 25–34, пришёл из стриминга, покупает лимитки онлайн, хочет комьюнити и статус. Не «дед с первопрессами».

## 2. Каталог фич

Оценки: 🔥 impact (1–3) / 🔨 effort (низ/сред/выс) / 🎯 fit к принципам ROADMAP (анти-grind, глубина > количество, лор).

### A3. «Год за вертушкой» (Vinyl Wrapped) — 🔥🔥🔥 🔨сред 🎯💯

Годовая (+ опц. месячная) share-карточка: сколько добавил за год, топ-жанры/десятилетия, самая редкая находка года, прирост стоимости коллекции в RUB, доля лимиток/коллекционок, страны прессов.

- **Почему:** Spotify Wrapped доказал — главный органический канал привлечения. Прямой контент под TikTok-стратегию из M10.
- **База:** og_image-генерация и share-карточки ачивок уже есть; collection_value_snapshot даёт динамику стоимости.
- **Реализация:** backend-агрегатор по коллекции за период → набор story-карточек (5–7 экранов) → share PNG. Запуск в декабре, пуш «твой год готов».
- **Метрика:** доля юзеров, зашеривших ≥1 карточку.

### C1. Радар вишлиста — 🔥🔥🔥 🔨низ→сред 🎯💯

**Самая недооценённая позиция старого Backlog. Retention-машина + affiliate-мостик.**

Два слоя:

**Активный — кнопка «Радар» в вишлисте.** Экран по каждой позиции: спарклайн динамики цены, текущие офферы РФ-магазинов (цена, магазин, наличие), медиана Discogs через pricing.py, события «появилось/пропало/подешевело».

**Пассивный — пуши.** «Пластинка из вишлиста появилась в Коробке Винила за 2400₽», «подешевела на 20%». Инфраструктура: парсеры с stock-refresh 6ч + notifications v2 (dedup, quiet hours) — всё готово.

- **Новое в данных:** история цен листингов — таблица `listing_price_history (listing_id, price_rub, is_available, seen_at)`, запись при каждом refresh с дельта-фильтром. Эта же таблица питает C3.
- **Никто в РФ этого не делает; Discogs — тем более.**
- **Метрика:** CTR пуша радара; клики → PurchaseClick (M7).

### C2. Режим «Диггер» — 🔥🔥 🔨сред 🎯💯

Сценарий: юзер на ярмарке/в магазине перед ящиком из 300 пластинок. На каждую интересную — вопросы: есть у меня? в вишлисте? ценник адекватный? редкая? Сейчас — 2 минуты ручного поиска по Discogs на штуку.

**Флоу:** кнопка «Диггер» → полноэкранная камера → скан обложки/штрихкода (существующий стек: barcode + Vision + CLIP) → **вердикт одним экраном, крупно:**

- 🟢 **«В ВИШЛИСТЕ!»** + медиана: «просят обычно 3200₽» → ценник 1500₽ = хватай
- 🔵 **«УЖЕ ЕСТЬ»** (+ какой пресс у тебя — вдруг этот другой)
- 🟣/💚 рарити-теги — уже считаются
- ⚪ ничего особенного → цена + кнопка «в вишлист»

Свайп вниз → следующий скан. Цель: **< 5 сек на пластинку.**

- **Отличие от текущего скана:** тот заточен на «добавить в коллекцию» (визард). Диггер — «решение о покупке за секунды». UI-обёртка поверх того же стека + офлайн-кэш вишлиста/коллекции (связь плохая на ярмарках).
- **Синергия:** офлайн-промо на ярмарках (канал M10), раздел «События» (D1).

### C3. «Дилы дня» в Маркете — 🔥🔥 🔨низ (после price history) 🎯👍

Событийный слой поверх `/market` — причина заходить ежедневно. Блоки сверху вниз:

1. **«Упало в цене»** — из `listing_price_history`: «−28% · было 4200₽ → 2990₽ · Vinyl.ru». Порог: drop ≥ 15% за 7 дней
2. **«Редкость в наличии»** — пересечение store_listing × рарити-флаги: коллекционка/лимитка появилась в РФ. Редкое событие → можно пуш вишлист-холдерам
3. **«Ниже мировой»** — цена RUB < медианы Discogs, пересчитанной формулой pricing.py: «2400₽ против ~3800₽ с доставкой». Только мы можем это посчитать
4. **«Последний экземпляр»** — обобщение Hot Stock pill (quantity=1 / мигающее наличие)

**Сценарий:** утренний заход → лента дилов → тап → карточка с оффером → клик в магазин = PurchaseClick. **Дилы = самособирающийся affiliate-инвентарь (M7).**

Ядро всех 4 блоков — история цен (общая с C1). После неё каждый блок — SQL-запрос.

### C4. Гид по прессингам — 🔥🔥 🔨сред 🎯💯

Вопрос №1 любого винил-чата: «какой пресс брать?» На master-странице — сравнение версий: год/страна/лейбл + цены + рекомендация. База: versions-экран + дамп уже есть; добавить слой ранжирования. v2 — UGC-заметки к прессингам (dead wax, качество мастеринга). Стыкуется с PRESSING_PRECISION.md.

### C5. Аудио-fingerprinting — 🔥 🔨выс 🎯👍 — 🧊 отложено

Shazam-style распознавание играющей пластинки. Дорого; без слоя прослушиваний ценность падает. Заморожено вместе со слоем A1/A2.

### D1. «События» — афиша винил-ивентов — 🔥🔥 🔨сред 🎯💯

Не строим клубы сами — становимся **афишей**. Discover-лист ивентов: прослушивание нового альбома в Коробке Винила, распродажа в AI Sheff, ярмарки (вкл. бывший E2 — календарь ярмарок МСК/СПб/регионы), DJ-сеты.

- RSVP «пойду» + видно кто из подписок идёт
- Магазины постят сами (им трафик) → **партнёрская валюта для M7-переговоров:** «мы приводим людей на ваши ивенты»
- Внутри ярмарочного ивента — вход в Диггер (C2)
- v1: ивенты добавляются вручную (admin), магазины — через нас; v2: кабинет магазина

### D2. Shelf challenges (сезонные) — 🔥 🔨низ 🎯💯

Редакционные сезонные челленджи: «октябрьский darkfolk», «месяц Мелодии». Без стриков и сгораний (принцип анти-grind). Контент для Telegram-канала (M10). Стыкуется с тематическими витринами D4.

### D3. Своп-борд (обмен без денег) — 🔥🔥 🔨сред 🎯💯

Промежуточный шаг до P2P (M8 — 16–21 недель): пометка «готов обменять» на записи коллекции + матчинг «в его трейд-листе твой вишлист, в твоём — его» → взаимный пуш → DM.

- Юридически лёгкий: нет денег → нет ЮKassa/эскроу/54-ФЗ
- Валидирует спрос на сделки за ~5% стоимости M8; прогревает аудиторию
- Обмены — душа винил-комьюнити
- Риски: disintermediation не критичен (денег нет); споры решаются репутацией — счётчик завершённых свопов в профиле

### D4. Витрина недели — 🔥 🔨низ 🎯👍

Публичная «коллекция недели». **Участвуют все** с публичным профилем — отдельная галка не нужна.

**Автоматический шорт-лист (сигналы):**
- Полнота карточек: фото, condition, заметки — «ухоженность»
- Разнообразие: страны прессов, десятилетия, жанры (глубина > количество)
- Рарити-плотность: доля collectible/limited (НЕ стоимость — иначе pay-to-win витрина)
- Свежая активность за неделю

**Финал:** ручной выбор из шорт-листа 5–10 с редакционной подписью («Коллекция недели: 60 лет японских прессов»). Ротация: один юзер не чаще раза в N месяцев. Формат: карточка в поиске/ленте + пост в Telegram-канал. Позже — тематические недели (стык с D2).

### E1. База советского винила («Мелодия») — 🔥🔥🔥 🔨сред 🎯💯

**Вечный moat. Discogs это не сделает никогда.**

Discogs покрывает СССР-прессы плохо и хаотично. Уже есть фундамент: user-submitted records + self-enriching индекс. Целевой ход — структурированный слой:

- Справочник заводов (АЗГ, ЛЗГ, ТЗГ, Ташкент...) с определением по матрице/логотипу
- ГОСТ-коды → датировка
- Каноничные карточки главных изданий «Мелодии»
- Ценники СССР как лор-фишка карточки

**Почему сработает:** аудитория 25–34 копает родительские полки; «Мелодия» снова печатает — тема живая; SEO-магнит («АЗГ матрица определить год») → органический трафик. Стык с M3 (user-submitted) и лор-ачивками M5 (серия по советскому винилу).

### E3. Карта магазинов РФ — 🔥 🔨низ 🎯👍

Магазины уже в базе (5 парсеров + store-native). Добавить физические адреса/часы → карта «винил рядом». Укрепляет партнёрства M7. Точки ярмарок из D1 — на той же карте.

### F1. «Крутани» — 🔥🔥 🔨низ 🎯💯

Кнопка **«Крутани»** в Поиске. Тап → горизонтальная лента обложек летит слева направо, замедляется, останавливается на рандомной редкости — **визуал jukebox / слот-машины**.

- Выборка: рандом из дампа с фильтром рарити (collectible/limited, или have < N + want/have высокий) — флаги уже считаются
- Результат: карточка → «в вишлист» / «крутануть ещё» / share («смотри что выпало»)
- Залипательная механика + спрятанная фича = делает раздел Поиска живым
- Backend: один endpoint random-выборки по существующим флагам. Основная работа — анимация ленты (Reanimated; физика замедления как в AutoRail)
- v2: тематические барабаны («только 60-е», «только Мелодия»), home-screen виджет «редкость дня» с той же логикой

### F2. NFC-метки на полке — 🔥 🔨сред 🎯👍 — backlog

Стикер на конверте → приложил телефон → карточка записи. Вау-эффект для TikTok; брендированные стикеры = мерч-микродоход. Без слоя прослушиваний ценность ниже — держим в backlog до пересмотра.

### Рекомендации «что добавить в коллекцию»

Это **M9.1 из ROADMAP** (content-based: score по genre/style/artist/label/year, reason-string, порог ≥10 записей, CTR ≥5%). Не дублируем — просто фиксируем: приоритет M9 поднимается, т.к. запросы «подскажи что мне подойдёт» — прямой запрос аудитории. Запуск после M2 (нужна юзербаза для калибровки).

## 4. Предложение по milestone'ам

Новые (нумерация продолжает ROADMAP):

- **M11. Радар и Дилы** — `listing_price_history` + C1 (экран радара + пуши) + C3 (4 блока в Маркете). Одно ядро данных, две фичи. Блокируется: M2. Блокирует: усиливает M7
- **M12. Живой Поиск** — F1 «Крутани» + C2 «Диггер» + C4 гид по прессингам. Общая тема: поиск из утилиты → в развлечение и инструмент покупки
- **M13. Комьюнити-слой** — D1 События + D4 Витрина недели + D2 challenges. Блокируется: M2 (юзербаза)
- **M14. Советский винил** — E1 (+ E3 карта попутно). Долгая, инкрементальная; можно вести фоном
- **D3 Своп-борд** — предлагаю как под-фазу M8 (M8.0 «Свопы») перед эскроу-фазами, а не отдельный milestone
- **A3 Wrapped** — сезонный спринт к декабрю; вешать на M10 (канал привлечения)

**Рекомендуемый порядок после M2:** M11 → A3 (декабрь) → M12 → M13 → M8.0 (свопы) → M14 фоном.
