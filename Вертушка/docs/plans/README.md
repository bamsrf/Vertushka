# docs/plans — карта папок

Планы разложены по темам. Главный living document — [../../ROADMAP.md](../../ROADMAP.md).

| Папка | Тема |
|---|---|
| `product/` | Стратегия, монетизация, P2P, аналитика, онбординг, принципы, NMT-диагностика |
| `appstore/` | Релиз: сабмит, ASO, TestFlight, pre-release аудиты, UGC-модерация |
| `market/` | Маркет РФ-магазинов: парсеры, офферы, affiliate, скейлинг, анти-грифинг |
| `discogs/` | Данные Discogs: дампы, ингест, локальный кэш, OAuth, точность прессингов |
| `covers/` | Обложки: архитектура, S3/imgproxy, rate-limits, распознавание |
| `search/` | Поиск: smart search, новинки, страницы артистов и фильтры |
| `collection/` | Коллекция и вишлист: оценка, радар цен, подарки, свои пластинки, рарити-теги |
| `achievements/` | Ачивки: планы, архетипы, XP, промпты пинов |
| `social/` | Сообщения, уведомления, пуши, публичные профили |
| `design/` | Дизайн-система v2, маскот, спиннер, дизайн-брифы |
| `quality/` | QA, багфиксы, безопасность, context layer (FTS/MCP) |

Новый план кладём в подходящую папку; ссылка из ROADMAP — `docs/plans/<папка>/<ИМЯ>.md`.
FTS-индекс (`.claude/mcp/indexer.py`) собирает `docs/plans/*.md` и `docs/plans/*/*.md` —
глубже одного уровня не вкладывать (или расширить glob).
