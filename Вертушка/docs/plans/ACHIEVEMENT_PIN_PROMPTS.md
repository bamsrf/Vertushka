# Промпты пинов ачивок — идея-заходы (4.2 → 5.3b)

> К каждой ачивке — короткий «заход идеи»: сюжет пина, главная фигура, акценты.
> Приклеивается к общему промпту (роль/материал/палитра/формат). Стиль soft enamel,
> золотая линия #D9A84E, navy outline, ember только на лейблах пластинок.
> Каждый пин — одна узнаваемая фигура ≥55% площади, читается при 64×64.
>
> Тиры (для совместимости с halo, не красить внутри): 💧 Простая · 🔵 Заметная · 🌸 Редкая · 🌌 Эпическая · ⚫ Легенда.
