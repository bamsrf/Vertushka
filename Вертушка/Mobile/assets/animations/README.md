# assets/animations

Lottie-анимации маскота Вертушки. ТЗ: `docs/plans/design/MASCOT_ANIMATION_SPEC.md`.

| Файл | Где | ТЗ |
|---|---|---|
| `loader-mascot.json` | Лоадеры внутри приложения (бесшовный луп) | 30fps, 1–2сек, 512×512, <100КБ |
| ~~`intro-mascot.json`~~ | **больше не используется** — интро переехало на видео | — |

## Интро теперь видео, а не Lottie

Заставка при старте играет `assets/video/intro-mascot.mp4` через `expo-video`
(см. `components/MascotIntro.tsx`). Растровый Lottie давал немые поломки
(webp-кадры, пропавшее поле `u` у ассетов) и белый экран вместо анимации.
`intro-mascot.json` оставлен на диске как архив — из бандла он выпал, потому что
на него больше нет ни одного `require()`. Новую версию интро подкладывать в
`assets/video/intro-mascot.mp4`, имя не меняя.

## ⚠️ Сейчас тут PLACEHOLDER

Оба файла — **временные заглушки** (брендовое синее кольцо + ember-точка).
Поле `nm` содержит суффикс `-PLACEHOLDER`. Дизайнер заменяет их на финальные
Bodymovin-экспорты, **имена файлов не меняя**.

После замены — проверить, что имя в `nm` без `-PLACEHOLDER` (иначе легко забыть,
что в приложении всё ещё заглушка).

## Подключение в коде

- `components/MascotLoader.tsx` — луп-лоадер (fallback на VinylSpinner).
- `components/MascotIntro.tsx` — интро (graceful skip если lottie-модуля нет).

Оба грузят JSON через `require()`, поэтому файлы обязаны существовать —
не удалять, только заменять содержимое.
