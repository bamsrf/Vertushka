Политика конфиденциальности

Дата вступления в силу: 2 июля 2026 г.

Приложение «Вертушка» (далее — «Приложение») предназначено для сканирования штрихкодов виниловых пластинок, ведения коллекции и вишлиста. Настоящая Политика описывает, какие данные мы собираем и как их используем.

1. Какие данные мы собираем

  • Данные аккаунта: email, имя пользователя, отображаемое имя. При входе через Apple / Google / Discogs — идентификатор соответствующего аккаунта.
  • Данные коллекции: информация о пластинках, которые вы добавляете (название, артист, год, обложка из Discogs).
  • Фотографии: аватар и фото пластинок, которые вы загружаете сами из галереи или с камеры.
  • Сообщения: личные сообщения между пользователями хранятся на сервере для доставки и синхронизации.
  • Данные вишлиста и подарков: пластинки в вишлисте, бронирования подарков.
  • Push-токен устройства — для доставки уведомлений (если вы разрешили уведомления).
  • Техническая информация: IP-адрес, тип устройства, версия ОС, отчёты о сбоях — для обеспечения безопасности и диагностики ошибок. Отчёты о сбоях обрабатываются на нашем собственном сервере и не передаются третьим лицам.

2. Как мы используем данные

  • Обеспечение работы Приложения: авторизация, хранение коллекции, синхронизация между устройствами.
  • Поиск информации о пластинках через Discogs API.
  • Отображение публичного профиля (если вы его активировали).
  • Улучшение качества работы и исправление ошибок.

3. Передача данных третьим лицам

Мы не продаём и не передаём ваши персональные данные рекламодателям или брокерам данных. Данные могут передаваться:

  • Discogs API — для поиска информации о пластинках (передаётся только поисковый запрос или штрихкод).
  • Apple / Google — при использовании Apple Sign In или Google Sign-In (в рамках стандартного протокола авторизации).
  • Expo Push Service — для доставки push-уведомлений (передаётся только push-токен устройства).

4. Хранение данных

Данные хранятся на сервере в Российской Федерации. Мы применяем стандартные меры защиты: шифрование паролей (bcrypt), HTTPS, ограничение доступа к базе данных.

5. Удаление аккаунта

Вы можете удалить аккаунт прямо в Приложении: Профиль → Удалить аккаунт. После удаления действует окно восстановления 30 дней (повторный вход восстанавливает аккаунт), затем все данные удаляются безвозвратно. Также можно запросить удаление, написав на support@vinyl-vertushka.ru.

6. Камера и галерея

Доступ к камере используется для сканирования штрихкодов и распознавания обложек пластинок. Доступ к галерее — только когда вы сами выбираете фото для аватара или обложки; на сервер передаются только выбранные вами изображения.

7. Изменения политики

Мы можем обновлять эту политику. Актуальная версия всегда доступна по адресу vinyl-vertushka.ru/privacy.

8. Контакты

По вопросам конфиденциальности: support@vinyl-vertushka.ru
